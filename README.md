# two-sum-calc

A small web app that solves the [Two Sum](https://leetcode.com/problems/two-sum/) problem in JavaScript. Add numbers to an array, set a target, and it tells you which two numbers add up to it.

## Features
- Push numbers onto the array
- Pop the last number off
- Set a target value
- Live array visual (matching pair highlights green)
- Result updates automatically as you change the array or target

## Files
- `index.html`
- `style.css`
- `script.js`

## Run it
Just open `index.html` in a browser, or host it with GitHub Pages.
